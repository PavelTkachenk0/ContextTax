# 0001 — Target .NET 10

- **Status:** Accepted (2026-06-04)

## Context
New greenfield project; we want a modern, long-runway platform and a forward-looking
public showcase. The dev machine has .NET 8 (LTS) and .NET 10 (preview).

## Decision
Target **.NET 10**, pinned via `global.json` (`rollForward: latestFeature`,
`allowPrerelease: true` while only preview is installed). Switch the pin to the GA
build when available.

## Consequences
- Newest C# / runtime; longest support window.
- Contributors need a .NET 10 SDK (GA recommended). CI installs the pinned SDK from
  `global.json`.
